# Bank Management System

A desktop Bank Management System developed using C# and Windows Forms.

## Features

- User Login and Authentication
- Client Management
- Add, Update, Delete, and Find Clients
- User Management
- Permissions and Access Control
- Transactions Management
- Currency Exchange
- Login Register and Activity Tracking

## Technologies Used

- C#
- Windows Forms
- .NET Framework 4.7.2
- Object-Oriented Programming (OOP)
- File Handling
- Git and GitHub
